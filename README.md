# Портфолио Софьи Толстых

Одностраничный сайт-портфолио AI-режиссёра и content producer. На сайте — шоурил, избранные работы, блок «Обо мне» и контакты.

## Как открыть

Откройте файл `index.html` в браузере (двойной клик или Live Server в редакторе).

Локальный сервер, если нужен:

```bash
npx --yes serve .
```

После запуска откройте адрес, который покажет команда (обычно `http://localhost:3000`).
